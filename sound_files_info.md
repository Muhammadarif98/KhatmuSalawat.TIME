# Звуковые файлы для приложения

## Счетчик

Для правильной работы счетчика требуются следующие звуковые файлы в директории `app/src/main/res/raw/`:

1. `counter_click.mp3` - короткий звук для сопровождения каждого нажатия кнопки (клик, увеличение, уменьшение, сброс)
2. `counter_milestone.mp3` - звук, который будет воспроизводиться при достижении значения, кратного 100

## Таймер

Звуковые файлы для таймера:

1. `timer_finish.mp3` - звук, воспроизводимый при завершении таймера

## Рекомендации по звукам

- Файлы должны быть в формате MP3
- Размер не должен превышать 200 KB
- Звук клика должен быть коротким (0.5-1 секунда)
- Звук достижения рубежа может быть длиннее (1-3 секунды)

## Важно!
Имена файлов ресурсов в Android должны содержать только строчные буквы (a-z), цифры (0-9) и символы подчеркивания (_).
Файлы нужно поместить в директорию `app/src/main/res/raw/`.
